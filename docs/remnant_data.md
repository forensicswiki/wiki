Remnant data is data that can be recovered after new information has
been written to the same storage medium. The glossary definition, in
[Terminology](terminology.md#remnant-data-and-residual-data),
describes it as the limit of data persistence at the physical or
hardware level.

The classic, best-documented cases are on magnetic media. Although
remnant data has been recovered from magnetic tapes and floppy disks,
there is no credible report that has been published in the open
literature that remnant data can be recovered from modern hard drives.

In volatile memory, the same limit appears as electrical or thermal
state retention after power-off, known as "data remanence"; the
glossary notes that cold-boot attacks exploit it by slowing the decay
of the RAM chips.
