Tsk-cp is a set of [LibCarvPath](libcarvpath.md) aware versions of
[The Sleuth Kit](the_sleuth_kit.md) tools (mmls-cp, dls-cp and icat-cp),
that are for use together with the normal versions of the other sleuthkit
tools in the process of doing [zero storage
carving](zero_storage_carving.md).
