MattockFS is a computer forensics actor-framework component, data
repository and message bus, implemented as a
[Fuse](https://en.wikipedia.org/wiki/Filesystem_in_Userspace) based user
space file system. It is a successor to [CarvFs](carvfs.md), uses
[CarvPath annotations](carvpath_annotations.md) to designate frozen
(immutable) repository data, and provides trusted provenance logs, a
sparse-capability AnyCast message bus and opportunistic BLAKE2 hashing
for actor-model based computer forensic frameworks.
