**Scalpel** is an open source file carver for [recovering deleted
data](recovering_deleted_data.md): it is significantly more efficient
than [Foremost](foremost.md), which it was originally based on, and
allows an examiner to specify a number of headers and footers to recover
file types from a piece of media. It is maintained by
[Golden G. Richard III](golden_g_richard_iii.md) and Lodovico Marziale,
and is being incorporated into [The Sleuth Kit](the_sleuth_kit.md).
