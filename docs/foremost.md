**Foremost** is a [Linux](linux.md) based program for [recovering
deleted files](recovering_deleted_data.md): it recovers files based on
their headers, footers, and internal data structures, using a
configuration file to specify the [headers and
footers](file_formats.md), and is intended to be run on [disk
images](disk_image.md). It served as the basis for the more modern
[Scalpel](scalpel.md).
