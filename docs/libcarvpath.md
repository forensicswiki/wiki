LibCarvPath is a shared library for carving and file system analysis
tools: it allows fragments represented by offset and size to be combined
in [CarvPath annotations](carvpath_annotations.md) that take the form of
file system paths, and addresses the limits of file system paths by
mapping extremely fragmented files to a uniquely identifying key in a
long-path database.
