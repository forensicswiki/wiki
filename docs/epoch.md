Epoch is a reference point from which time is measured. It typically describes the date and time
that is represented by the number 0.

The following epochs are known:

| Applications | Date and Time | Reference |
| --- | --- | --- |
| Microsoft Windows (FILETIME and SYSTEMTIME) | January 1, 1601 | [File Times](https://learn.microsoft.com/en-us/windows/win32/sysinfo/file-times) |
| Unix (or POSIX) | January 1, 1970 | |
| Apple HFS | January 1, 1904 | |
| FAT | January 1, 1980 | |
| Palm OS | January 1, 1904 | |
