**BCWipe** is a secure data deletion tool for
[Windows](windows.md) and [Unix](unix.md)-like
operating systems.

It supports US DoD 5200.28-STD
compliant data deletion as well as the "[Peter
Gutmann](peter_gutmann.md) wiping scheme".
