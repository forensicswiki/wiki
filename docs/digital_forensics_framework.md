Digital Forensics Framework (DFF) was a free, open source computer forensics
platform built on top of a dedicated Application Programming Interface (API).
It provided a graphical user interface, a command line interface, and direct
scripting through Python. Development stopped; the last stable release was
version 1.3.0 on February 28, 2013.
