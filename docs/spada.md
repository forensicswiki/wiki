Development of SPADA stopped; the last release was in September 2010.

SPADA, or System Preview And Data Acquisition, is a [Live CD](live_cd.md)
based on [Knoppix](knoppix.md).

## Caution

SPADA automounts file systems during the hardware detection process and
recovers some of them if required.
