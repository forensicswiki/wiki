analyzeMFT is designed to fully parse the $MFT file system metadata file from an
[NTFS file system](new_technology_file_system_\(ntfs\).md) and present the results in multiple
formats. It was written in Python 2 and is no longer maintained.

There is a Python 3 fork of analyzeMFT, analyzeMFT3, which is also no longer maintained.
