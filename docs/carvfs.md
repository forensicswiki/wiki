CarvFs is a modular [Fuse](https://en.wikipedia.org/wiki/Filesystem_in_Userspace) based user
space file system on top of [LibCarvPath](libcarvpath.md). CarvFS makes
CarvPath style annotations as used by LibCarvPath available as files.
Using CarvFs makes it possible to process carved entities using
[zero storage carving](zero_storage_carving.md).

For use in computer forensic frameworks, CarvFS is superseded by the
closely related [MattockFS](mattockfs.md).
