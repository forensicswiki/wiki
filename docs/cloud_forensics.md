Cloud forensics is a specialized branch of digital forensics that focuses on identifying,
acquiring, preserving, analyzing, and reporting on digital evidence within cloud computing
environments such as:

* IaaS; Infrastructure as a service
* PaaS; Platform as a service
* SaaS; Software as a service
