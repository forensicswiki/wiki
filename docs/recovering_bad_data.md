A forensic investigator uses techniques that can **recover bad data** in order
to recover data from a [disk drive](hard_drive.md) that is malfunctioning.

Typically the drive's own error-handling is bypassed or disabled, and the
media is re-read or skipped around sector by sector so that whatever is
still readable ends up in the image.
