FreeViewer offers free viewers for email file formats and
SQLite database files.

## Products

* [Free MBOX Viewer](https://www.freeviewer.org/mbox/) - A free viewer for
  MBOX email files.
* [Free MSG Viewer](https://www.freeviewer.org/msg/) - A free viewer for
  MSG email files.
* [Opera MBS Viewer](https://www.freeviewer.org/mbs/) - A viewer for
  Opera MBS email files.
* [SQLite Forensics](https://www.freeviewer.org/sqlite/forensics/) - A
  forensic analysis tool for SQLite database files.

### MSG Viewer

MSG Viewer is a freeware application to open and view
single email file of Microsoft Outlook without platform availability.

#### Features

The email data in an MSG file can be viewed in modes including; normal,
hex, MIME, HTML, etc., for respective purposes. Further, this
application can be upgraded to a licensed version adding facilities to
export into PDF. The upgradation to licensed version has to be executed
through purchase.
