Snarl is a discontinued [FreeBSD](freebsd.md) based [Live CD](live_cd.md) that
included [Autopsy](autopsy_forensic_browser.md) and [the Sleuth Kit](the_sleuth_kit.md).
The last release, version 1.13, was published in 2013.
