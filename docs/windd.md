WinDD was a set of Windows physical memory acquisition tools (or dumpers) for
both 32-bit and 64-bit [Windows](windows.md). It was deprecated in favor of
the MoonSols Windows Memory Toolkit.

> Note that WinDD should not be confused with "WinDD - Disk Dump for Windows"
